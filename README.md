# Inputmask com Next.js

Exemplos de campos de texto usando o [inputmask](https://github.com/RobinHerbots/Inputmask) no Next.js.

## Componentes disponíveis

- [`<BRLField>` (campo de moeda)](src/components/BRLField/index.tsx);
- [`<CEPField>` (campo de CEP)](src/components/CEPField/index.tsx);
- [`<CNPJField>` (campo de CNPJ)](src/components/CNPJField/index.tsx);
- [`<CPFField>` (campo de CPF)](src/components/CPFField/index.tsx);
- [`<PhoneField>` (campo de telefone)](src/components/PhoneField/index.tsx).
